## Project setup

Start with the root [README](../README.md) for Docker and local-development setup, configuration, CLI commands, and validation commands. See [Contributing](../CONTRIBUTING.md) for code standards and pull-request expectations.

Documentation should describe current, verified behavior. Planning notes, migration checklists, and consolidation records belong in project issues or internal working notes, not in this product documentation. Historical implementation claims should be verified against the current source before being documented as facts.
